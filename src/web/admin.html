Add a report

In .md and .txt files, start each page with a line [[page 1]], [[page 2]] and so on so citations show page numbers. Without markers, pages are split automatically.

Figures from the report (optional)

Add figures if people will ask for numbers (market size, growth, regional share). Without them the report is still searchable and answers quote its text. Use USD billions for market size and percent for CAGR and share. Each row needs a value; remove rows you do not need.
